# Video clips

Put `.mp4`, `.mov`, `.mkv`, `.avi`, `.webm` or `.m4v` clips here. They appear in the app's file list
(reload the page after adding one).

Clips are not committed to the repository: they are large and often belong to someone else.

To make a synthetic test clip:

```
.venv\Scripts\python scripts\make_test_clip.py
```
